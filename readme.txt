# 📌 Projeto Pizzaria - HTML & CSS  

Este projeto foi desenvolvido como parte do curso de **Desenvolvimento Web** da **Avanti** em parceria com o **IFCE**. O objetivo era criar um site para uma **pizzaria**, utilizando apenas **HTML e CSS**, sem o uso de JavaScript ou frameworks.  

O site conta com diversas páginas, cada uma com uma funcionalidade específica, como **cardápio, pedidos, promoções e localizador de lojas**. A estrutura e o design foram organizados para proporcionar uma navegação intuitiva e responsiva.
